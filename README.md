## About me 👨🏻‍💻

I'm a **Software Architect** in the automotive industry, working on an **AOSP-based In-Vehicle Infotainment** system for a Russian EV project. I sit between engineering teams, hardware, and design — turning Figma mockups and stakeholder ideas into precise functional specs, API contracts, and traceable requirements that actually ship.

Before automotive, I automated industrial processes as a **Python developer at Severstal** — one of Russia's largest steel producers. That's where I learned to respect systems that run 24/7 and never forgive bad code.

- 🚗 IVI platform on AOSP & RTOS — notifications, HMI, vehicle service integration
- 📐 Requirements engineering, system design, API specs (REST, AIDL)
- 🏭 Background in industrial automation — Python, data pipelines, process control
- 🎓 Final-year student at **NUST MISIS** (Technological Machines & Equipment)
- 🧠 Diploma project: **ML-based predictive maintenance** for industrial equipment
